# docs

What each document here is for. The rules every contributor follows are at the repository's root (`AGENTS.md`,
`GUIDELINES.md`, `ARCHITECTURE.md`, `PLATFORM_GUIDELINES.md`, `LIBRARIES.md`); the plan is `ROADMAP.md`.

| Document | What it holds |
|---|---|
| `HANDOFF.md` | Where the work stands now and what comes next: read it first |
| `history.md` | How each milestone went, as the handoff told it at the time |
| `roadmap/` | The done milestones' items and specs (M1 to M4b), under the numbers every document cites |
| `macos-redesign.md` | The macOS redesign: the picks, their dependencies and the order of the work |
| `performance.md` | Every performance pass: what was measured, where memory went and what was cut |
| `answer-quality.md` | How the chat's answers are judged, and the rules that came from it |
| `spikes/` | Short experiments, dated, each with the question, what was tried and the decision |
