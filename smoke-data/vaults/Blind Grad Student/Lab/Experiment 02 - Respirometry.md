# Experiment 02 – Respirometry

Oxygen consumption of four-arm plutei at three temperatures. Method from [[Tanaka 2022 - Respirometry methods]]:
2 mL glass chambers, 30 larvae per chamber, sensor spots calibrated the same morning.

| Tank | Temperature (°C) | O2 consumption (pmol per larva per hour) | Note |
|---|---|---|---|
| A | 14 | 4.2 | |
| B | 14 | 3.8 | |
| C | 20 | 6.1 | |
| D | 20 | 6.5 | |
| E | 24 | 8.9 | discarded: blank drift 9 % |
| F | 24 | 9.3 | |

- Room temperature drifted by 0.4 °C during the afternoon run.
