# Volunteer Induction

Checklist for every new volunteer, mentored by [[Ruth Okafor]].

- [ ] DBS check returned and logged
- [ ] Read the [[Safeguarding Policy]] and sign the declaration
- [ ] Tour of the home and fire exits
- [ ] Shadow two sessions before leading one
- [ ] Name badge printed in large letters
- [ ] Added to the volunteer group chat
