# Software UI EN-PT

For [[Verba Global]] software jobs, including [[VG-2026-018 UI strings]].

## Length limits
- Buttons: 18 characters maximum, verb in the infinitive ("Guardar", "Cancelar")
- Menu items: 30 characters
- Tooltips: 80 characters

## Terms
| English | Portuguese (PT-PT) |
|---|---|
| Save | Guardar |
| Settings | Definições |
| Sign in | Iniciar sessão |
| Dashboard | Painel |
| Invoice | Fatura |
| Upload | Carregar |
| Download | Transferir |

Never "salvar" or "deletar" — those are Brazilian.
