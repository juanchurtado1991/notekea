# Checklist

Delivery checklist for every translation job. #workflow

- [ ] Run QA in Tradora (numbers, tags, double spaces)
- [ ] Check units and decimal separators
- [ ] Spellcheck with Revisa
- [ ] Check the glossary terms are consistent
- [ ] Re-read the whole target once, without the source
- [ ] Name the file the way the agency wants
- [ ] Deliver and log the job in [[Invoices 2026]] when invoiced
