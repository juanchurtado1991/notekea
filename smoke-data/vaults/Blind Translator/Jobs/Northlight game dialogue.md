Dialogue and UI for a narrative adventure game ("Ashfall Harbour"), EN → PT-PT. Client:

## Files and tools
- Strings come as a Tradora package per batch; each string has an ID, a speaker and a character limit
  for subtitles (42 characters per line, two lines maximum)
- Context comes from a shared spreadsheet with the scene descriptions and a few concept images
- Queries go in the shared query sheet, one row per string ID
- Variables look like [PLAYER] and [ITEM]; never translate or move the brackets

## General style
- Informal "tu" between the young characters, "você" for the harbour officials
- The game is rated for 12+: strong language must be toned down, no slurs
- Keep sentences short in subtitles; split long lines at natural pauses
- Song lyrics in the tavern scenes are written by the studio: keep them in English, do not translate

## Characters
- **Mara** — the player character's sister. Quick, sarcastic, modern Lisbon speech.
- **Captain Ilse** — the harbour master. Formal, clipped, uses nautical words.
- **Dov** — a smuggler. Slangy but not crude; Hannah asked to avoid real-world criminal jargon.
- **The Archivist** — speaks in riddles. Keep the rhymes where possible, meaning first.
- **Old Fenwick** — the ferryman, appears from chapter 2.
