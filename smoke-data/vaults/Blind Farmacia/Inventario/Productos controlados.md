# Productos controlados

Psicotrópicos y estupefacientes. Solo se despachan con receta retenida o receta cheque, y cada movimiento se
anota en el libro oficial el mismo día. Cuadratura al cierre de cada mes.

La caja fuerte se abre con la llave que lleva el químico farmacéutico de turno (de lunes a viernes, yo).
