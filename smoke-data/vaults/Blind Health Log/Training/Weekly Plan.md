# Weekly Plan — training

Built with [[Mike Brenner]]. Mileage grows by at most one mile per week on the long run.

|-----|---------|

| Thursday | Easy run 4 miles + 6 x 20 s strides |
| Friday | Rest, mobility 15 min |
| Saturday | Long run 7 miles, flat route |
| Sunday | Cross-training: 45 min bike or swim |
