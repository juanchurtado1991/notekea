# Return to Run Protocol

From [[Sarah Whitlock]]. Start only after passing the return-to-run test (done 2026-09-30, passed).

## Stages
1. Run/walk intervals (4:1, then 5:1), every other day.
2. Continuous easy running up to 30 minutes.
3. Add one run per week, then grow the long run by one mile per week.
4. Strides after 4 weeks of pain-free easy running.
5. Hills and speed work only when cleared by the physio.

## Pain rules
- During a run: up to 3/10 is acceptable.
- Next morning: must be back to baseline. If not, drop back one stage.
- Sharp pain = stop and walk home.
