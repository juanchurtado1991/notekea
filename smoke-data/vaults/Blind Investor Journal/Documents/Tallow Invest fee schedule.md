# Tallow Invest fee schedule

Effective 2026-07-01. Copied from the website so I can check charges against [[Fees]].

| Item | Fee |
|------|-----|
| Brokerage, trade up to $3,000 | $5.50 flat |
| Brokerage, trade over $3,000 | 0.12% of trade value |
| Auto-invest buys | same as brokerage, per fund |
| Dishonour fee (failed direct debit) | $22.00 |
| Currency conversion (FX) on overseas trades | 0.60% |
| Account keeping | nil |
| Inactivity | nil |
| Transfer out to another broker | $54.00 per holding |

Distributions paid in cash go to the linked bank account at no cost.
