# Art Style

- Palette: 32 colours, cold blues and one warm lantern orange (#F2A541)
- Sprites: 16x16 for small enemies, 24x32 for characters
- Outlines: dark blue, never black
- Light: the lantern is the only warm light in the night scenes

Characters by [[Sam Okafor]]. Reference board shared with both artists on 2026-06-05.
