# Stairwell windows

Five old wooden windows in the stairwell, one per floor, single glazed, draughty.

- March 2026: assembly asked for a study (see [[Minutes 2026-03-19]]).
- Study by the architect, Ms Rauch: replace with wood-aluminium, triple glazed.
- Budget line: 11200 EUR (Renovation budget 2027).
- To be done together with the facade, while the scaffolding is up.
