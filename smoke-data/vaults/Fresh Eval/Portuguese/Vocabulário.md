# Vocabulário

Palabras que siempre se me olvidan. Español → português.

## Casa
- grifo → torneira
- fregadero → lava-loiça
- enchufe → tomada
- nevera → frigorífico
- escalera → escadas

## Ciudad
- autobús → autocarro
- acera → passeio
- semáforo → semáforo (¡igual!)
- billete → bilhete

## Trabajo
- encargo → encomenda
- plazo → prazo
- factura → fatura
- boceto → esboço

## Falsos amigos
- *exquisito* ≠ esquisito (raro)
- *polvo* = pulpo, no polvo
- *apelido* = apellido, no apodo
