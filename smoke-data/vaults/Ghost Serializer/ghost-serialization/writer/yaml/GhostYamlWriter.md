# GhostYamlWriter

The low-allocation writer that turns Ghost values into block-style YAML bytes.

## What it is about

This is the write side of the YAML channel. A generated or built-in [[GhostYamlSerializer]] calls its methods (`beginObject`, `name`, `value`, `endObject`, ...) and the writer emits correctly indented YAML to a byte sink. It works on any [[GhostGenericByteSink]], so one body of code serves two backings: a streaming Okio `BufferedSink` and the in-memory [[FlatByteArrayWriter]] used by the pooled encode path.

## How it works

The writer keeps a small stack in two fixed `IntArray`s of size `MAX_DEPTH + 1`: `contexts` says whether each level is an object or an array, and `itemCounts` how many entries it has written. Block YAML needs layout decisions before each token, which the writer takes in `prepareValue` and `name`:

- In an array, each item starts with a newline, the indentation and `- `.
- In an object, `name` writes a newline plus indentation (except for the very first key of the root), then the key and a colon, and sets `pendingSpace` so that the next scalar gets one space after the colon.
- A nested object or array right after a dash stays on the dash line (`justWroteDash`), which gives the compact `- key: value` form.

The decision logic itself lives in [[GhostYamlWriterHelpers]] as inline functions that return packed flags, so the class only updates its three fields. Opening a scope beyond `MAX_DEPTH` (64) throws [[GhostYamlException]]. An object or array that ends with no children would leave a dangling `key:`, so `endObject` and `endArray` backfill `{}` or `[]`.

Strings are always double-quoted. Short ones (up to 64 chars) made of printable ASCII with no `"` or `\` are written directly; anything else goes through the escaping helper. Numbers use `writeLong` with a pooled scratch array (no `toString`), `ULong` values above `Long.MAX_VALUE` are quoted, and `Double` and `Float` use `.nan`, `.inf` and `-.inf` for non-finite values.

## The code

Two constructors choose the backing. The private one takes the generic sink:

```kotlin
class GhostYamlWriter private constructor(
    @PublishedApi internal val sink: GhostGenericByteSink
) {
    constructor(sink: BufferedSink) : this(BufferGhostByteSink(sink = sink))

    @InternalGhostApi
    constructor(flatBuffer: FlatByteArrayWriter) : this(flatBuffer as GhostGenericByteSink)
```

Opening a scope checks depth, prepares layout and pushes the type:

```kotlin
prepareValue(isStructural = true)
val nextDepth = currentDepth + 1
contexts[nextDepth] = WR.TYPE_ARRAY
itemCounts[nextDepth] = 0
depth = nextDepth
```

`name(key: String)` quotes keys only when `keyNeedsQuoting` says so; `name(key: ByteString)` writes a pre-encoded key as is. The `writeField(header, value)` overloads take a header such as `"id":` generated by the compiler, extract the bare key with `extractKey`, and write name and value together. `reset()` clears the layout state for reuse by the pool; `release()` also returns the scratch buffer.
