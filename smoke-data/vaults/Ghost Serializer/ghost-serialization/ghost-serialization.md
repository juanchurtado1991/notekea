# ghost-serialization

The runtime: readers and writers for JSON (bytes, strings, streaming), YAML and Protobuf, the built-in serializers and the registry that finds generated ones.

Part of [[Ghost Serializer]]. Its notes, by package:


## contract

- [[AbstractGhostRegistry]]: A skeletal `GhostRegistry` that supplies defaults for everything except `getSerializer`.
- [[AbstractGhostSerializer]]: A skeletal base class for `GhostSerializer` that fills in the channels a serializer does not implement itself.
- [[GhostRegistry]]: The interface for a module's collection of serializers, generated per module by the compiler plugin.
- [[GhostSerializer]]: The interface every Ghost serializer implements, whether generated by the compiler or written by hand.
- [[GhostSerializerLink.native]]: The Kotlin/Native declaration of the `@GhostSerializerLink` annotation.
- [[GhostSerializerLink.wasmJs]]: The Kotlin/Wasm declaration of the `@GhostSerializerLink` annotation that ties a class to its generated serializer.

## exception

- [[GhostJsonException]]: The exception Ghost throws for malformed JSON or invalid structure, carrying the path, line, column and a fix hint.
- [[GhostJsonHintMessages]]: A holder of constant, developer-facing hint strings for common JSON parse errors.

## parser/bytes

- [[ByteArrayGhostSource]]: A `GhostSource` backed by an in-memory `ByteArray`, with the scanning logic shared by every platform.
- [[GhostJsonFlatReader]]: The main JSON reader for in-memory byte arrays: it reads a flat `ByteArray` directly, with no interface dispatch on the hot path.
- [[GhostSwar]]: The common side of Ghost's "SIMD within a register" byte reading: an `expect` function that loads eight bytes into one `Long`, a portable fallback, and a table of length masks.
- [[GhostSwar.android]]: The Android implementation of `ghostReadLong8`, which assembles the eight-byte word by hand.
- [[GhostSwar.jvm]]: The JVM implementation of `ghostReadLong8`, which turns eight bytes of a `ByteArray` into a `Long` with a single memory load.
- [[GhostSwar.nonJvm]]: The `ghostReadLong8` actual shared by Kotlin/Native (iOS and other native targets) and Kotlin/Wasm.

## parser/bytes/extensions

- [[GhostJsonFlatReaderCapture]]: Extension functions that capture the next complete JSON value of a byte reader as raw UTF-8 bytes, without decoding it.
- [[GhostJsonFlatReaderChars]]: One extension function, `nextChar`, which reads a JSON string that must contain exactly one character.
- [[GhostJsonFlatReaderCollections]]: Inline helpers that decode JSON arrays and objects into Kotlin collections, plus `decodeResilient`, which turns a bad value into `null`.
- [[GhostJsonFlatReaderNumbers]]: The number readers for the byte channel: `Int`, `Long`, `ULong`, `Float`, `Double` and `skipNumber`.
- [[GhostJsonFlatReaderStrings]]: String reading for the byte reader: `readQuotedString` with a string pool, `skipQuotedString`, and the helper that decodes `\uXXXX` escapes.
- [[GhostJsonFlatReaderSubsystem]]: The field-name matcher of the byte reader: `internalSelect`, which turns a JSON key into the index of a Kotlin property.

## parser/common

- [[AbstractGhostSource]]: A skeletal base class that gives `GhostSource` implementations sensible defaults for three members most of them do not need to customize.
- [[GhostBase64]]: Base64 encoding and decoding for `ByteArray` values, written without platform APIs so it works on every Kotlin target.
- [[GhostBooleanCoercionHelpers]]: A reader-independent matcher that turns lenient text such as `yes`, `Off` or `1` into a Boolean without creating a String.
- [[GhostBufferGrowth]]: A single internal function that doubles a temporary scratch buffer, copying what was written and handing the old one back to the pool.
- [[GhostDecimalExactRounding]]: Exact decimal-to-binary rounding helpers, with a small arbitrary-precision integer class, used where a platform's own `toDouble()` is not correctly rounded.
- [[GhostDecimalLiteralParsing]]: Two `expect` functions that convert a decimal number literal into a correctly rounded `Double` or `Float`.
- [[GhostDecimalLiteralParsing.jvmAndroid]]: The JVM and Android `actual` for decimal-literal parsing: the two functions simply call `toDouble()` and `toFloat()`.
- [[GhostDecimalLiteralParsing.native]]: The Kotlin/Native `actual` for converting a decimal literal to `Double` or `Float`: it takes the platform's approximate `toDouble()` and refines it to the correctly rounded result.
- [[GhostDecimalLiteralParsing.wasmJs]]: The Wasm-JS `actual` for turning a decimal literal into a correctly rounded `Double` or `Float`, by borrowing the JavaScript engine's `Number()`.
- [[GhostDiscriminatorPeeker]]: Looks ahead in a JSON object to read the value of a type-discriminator key (such as `"type"`) without consuming or fully parsing anything.
- [[GhostFormatUtils]]: An internal object holding two precomputed 100-entry tables used to print numbers two digits at a time.
- [[GhostHeuristicDefaults]]: An internal object that holds the baseline numbers behind every platform's `GhostHeuristics`.
- [[GhostHeuristics]]: The `expect object` that declares the performance and safety knobs Ghost reads at runtime, implemented separately for each platform.
- [[GhostHeuristics.android]]: The Android `actual` of `GhostHeuristics`: the shared defaults, except that collections are capped at 50,000 items.
- [[GhostHeuristics.jvm]]: The JVM `actual` of `GhostHeuristics`: higher defaults than other platforms, and every limit can be overridden with a system property.
- [[GhostHeuristics.native]]: The Kotlin/Native `actual` of `GhostHeuristics`: every tuning value is the shared default.
- [[GhostHeuristics.wasmJs]]: The Kotlin/Wasm-JS `actual` of `GhostHeuristics`: the tuning knobs for Ghost on browsers, with one value that is decided at runtime.
- [[GhostNumericParseHelpers]]: Small inline building blocks for parsing integers: overflow-checked digit accumulation, safe narrowing to smaller integer types, and three byte predicates.
- [[GhostSource]]: The interface through which Ghost's byte readers see their input, whether it is an in-memory array or an Okio stream.
- [[GhostSource.apple]]: The Apple (iOS, macOS and friends) `actual` of `createByteArraySource`, returning the standard `ByteArrayGhostSource`.
- [[GhostSource.jvmAndroid]]: The JVM and Android `actual` of `createByteArraySource`, which returns a byte-array source that decodes plain-ASCII strings faster.
- [[GhostSource.wasmJs]]: The Wasm-JS `actual` of `createByteArraySource`: it wraps a byte array in the plain `ByteArrayGhostSource`.
- [[GhostSourceCommon]]: The shared scanning kernels behind every `GhostSource`: skip whitespace, find a closing quote, hash and scan a string, and compare bytes to a string, all tuned for speed.
- [[GhostUtf8PositionBridge]]: Converts positions in a Kotlin `String` (counted in chars) to and from positions in its UTF-8 encoding (counted in bytes), without building the byte array.
- [[GhostWrappedKeysCapture]]: A short-lived collector that stores several JSON values from different keys and reassembles them into one synthetic object, for the `@GhostWrappedKeys` feature.
- [[JsEngineDetect.wasmJs]]: A one-function file that guesses, from the browser's user agent, whether the page runs on JavaScriptCore (Safari and iOS) so Ghost can choose a faster way to encode to a string.

## parser/common/constants

- [[GhostJsonErrorMessages]]: One `object` that holds the text of every JSON parse and decode error, shared by all reader channels.
- [[GhostJsonNumericLimits]]: The numeric thresholds of Ghost's parser and formatter: overflow bounds for integers, precision limits for floating point, depth limit and a table of powers of ten.
- [[GhostJsonScanConstants]]: The named constants of Ghost's scanning layer: SWAR masks, sentinel values, unroll offsets, perfect-hash defaults, string-pool sizes and the layout of a packed scan result.
- [[GhostJsonTokens]]: The vocabulary of the parser: named byte and char codes for JSON syntax, case-folded letters, control characters, hex tables, surrogate ranges, BOM markers and generated type names.
- [[GhostJsonWriterConstants]]: The constants of Ghost's output side and of its UTF-8 handling: pre-encoded literals, buffer sizes, escape tables and the arithmetic constants of UTF-8 encoding.

## parser/common/json

- [[DetectedJsonEncoding]]: A tiny internal result type that says which text encoding a JSON document uses and how many leading bytes are a byte-order mark.
- [[GhostEiselLemire]]: An allocation-free implementation of the Eisel-Lemire algorithm that converts a decimal mantissa and exponent into the raw bits of the nearest `Double`.
- [[GhostEiselLemirePowers]]: The large lookup table of 128-bit approximations of powers of ten that the Eisel-Lemire float-parsing algorithm multiplies against.
- [[GhostJsonCommaValidationHelpers]]: Four inline kernels that enforce comma rules (no missing, extra or trailing commas) for arrays and objects.
- [[GhostJsonEscapeValidation]]: A one-predicate file that says whether a character after a backslash is one of JSON's simple escape letters.
- [[GhostJsonFloatParseHelpers]]: The shared kernels that read a JSON floating-point number: collect the digits into a mantissa and exponent, then scale them to a correctly rounded `Double` or `Float`.
- [[GhostJsonIntegerParseHelpers]]: Inline kernels that read `Int` and `Long` values from a run of digits, with a precise slow path for exponent forms like `1e2`.
- [[GhostJsonKeySelectHelpers]]: The shared pieces of Ghost's field dispatch: hashing a key's first bytes, skipping an unknown key, and resolving a key that contains escapes.
- [[GhostJsonNumberValidationHelpers]]: Inline kernels that check or skip the syntax of a JSON number without producing a value: the optional quote and minus, leading zeros, and the digits of integer, fraction and exponent.
- [[GhostJsonPathReconstruction]]: Rebuilds the JSONPath of an error by re-scanning the part of the document before it, so the happy path never pays for path tracking.
- [[GhostJsonPathTracker]]: A compact stack that remembers where the parser is in the document, so a parse error can say `$.items[3].name` instead of only a byte position.
- [[GhostJsonQuotedStringSlow]]: The slow path for reading a quoted JSON string that contains escape sequences, shared by the flat and streaming byte readers.
- [[GhostJsonStructureHelpers]]: Shared inline kernels for the structural tokens of JSON: opening and closing objects and arrays, the `:` separator, and skipping a whole value.
- [[GhostJsonUtf8Input]]: Normalizes any RFC 8259 JSON input (UTF-8, UTF-16 or UTF-32, with or without BOM) to UTF-8 before it reaches the parsers.
- [[GhostJsonValueCaptureScan]]: One iterative scanner that finds the end of a complete JSON value while validating its grammar, used to capture a value as `RawJson` without decoding it.
- [[GhostJsonValueHelpers]]: Two shared inline kernels for reading a boolean and for the "null or value" pattern, written once for the streaming and string readers.
- [[JsonEncodingKind]]: An internal enum naming the five text encodings Ghost recognizes at the start of a JSON document.
- [[JsonReaderOptions]]: The per-class field-name table that a generated deserializer hands to a reader so it can map JSON keys to field indexes very quickly.

## parser/proto

- [[GhostProtoJsonFlatReader]]: A byte reader specialized for proto3 JSON, the canonical JSON form of Protocol Buffers messages.
- [[ProtoJsonFlatReaderBase64]]: Decodes a proto3 `bytes` field, which JSON carries as a base64 string, into a `ByteArray`.
- [[ProtoJsonFlatReaderIntegers]]: Reads proto3 JSON `int32`, `int64` and `uint64` values, accepting quoted numbers and zero-fraction decimals.
- [[ProtoJsonFlatReaderNumbers]]: Proto3-aware readers for floating-point values, enums and `uint32` on [[GhostProtoJsonFlatReader]].

## parser/streaming

- [[GhostJsonReader]]: The general JSON reader: it works over any `GhostSource`, which means either a byte array or an Okio stream.
- [[GhostJsonReaderCapture]]: Raw JSON capture for the general reader: `captureRawJson` and `captureRawJsonBytes`, which work for both in-memory and streaming sources.
- [[GhostJsonReaderNumbers]]: Number reading for the general reader: `nextInt`, `nextLong`, `nextULong`, `nextFloat`, `nextDouble` and `skipNumber`.
- [[GhostJsonReaderSubsystem]]: The structural operations of the general reader: objects, arrays, separators, null, booleans, strings, collections, field selection, `skipValue` and resilient decoding.
- [[StreamingGhostSource]]: A `GhostSource` that reads from an Okio `BufferedSource`, so Ghost can parse a JSON document of unknown size without holding all of it in memory.

## parser/strings

- [[GhostCharSwar]]: Two tiny helpers that pack four UTF-16 characters into one `Long`, the character-array version of the SWAR trick used on bytes.
- [[GhostJsonStringReader]]: The JSON reader for in-memory `String` payloads, the default `textChannel` path: it parses UTF-16 characters directly instead of encoding the text to bytes.
- [[GhostJsonStringReaderCapture]]: Raw JSON capture for the `String` reader: it finds the next complete value and returns it as UTF-8 bytes or a `RawJson`.
- [[GhostJsonStringReaderNumbers]]: Number reading for the `String` reader: `nextInt`, `nextLong`, `nextULong`, `nextFloat`, `nextDouble` and `skipNumber`.
- [[GhostJsonStringReaderQuotedStrings]]: String value reading for the `String` reader: `readQuotedString`, `skipQuotedString`, and the escape-decoding slow path.
- [[GhostJsonStringReaderSubsystem]]: The structural half of the `String` reader: objects, arrays, separators, null, booleans, collections and field-name selection.

## parser/yaml

- [[GhostYamlAnchorSubsystem]]: The part of the YAML reader that handles anchors (`&name`), aliases (`*name`) and merge keys (`<<`).
- [[GhostYamlBlockScalarSubsystem]]: The parser for YAML block scalars: multi-line text introduced by `|` (literal) or `>` (folded).
- [[GhostYamlBlockStyleSubsystem]]: The parser for YAML block collections: indentation-based mappings (`key: value`) and sequences (`- item`).
- [[GhostYamlCursorTraversal]]: The second phase of YAML reading: the functions that walk an already parsed tree through the same cursor API Ghost uses for JSON.
- [[GhostYamlDocumentReading]]: The entry points for parsing a whole YAML document, or a stream of documents separated by `---`, plus the reader reset used by the pool.
- [[GhostYamlErrorReporting]]: A single extension function, `yamlError`, that every parser file calls to fail with a positioned `GhostYamlException`.
- [[GhostYamlExplicitKeySubsystem]]: The reader for YAML's explicit mapping entries, written as `? key` followed by `: value`.
- [[GhostYamlFlatReader]]: The YAML reader: the class that holds the parser state and exposes the same cursor-style API that generated serializers use for JSON.
- [[GhostYamlFlowStyleSubsystem]]: The parser for YAML flow collections, the JSON-like forms `{a: 1, b: 2}` and `[x, y, z]`.
- [[GhostYamlFoldHelpers]]: Two small pure helpers for folding a multi-line plain scalar into one string.
- [[GhostYamlKeyReading]]: Reads the key of a YAML mapping entry: a plain scalar that ends at `:`, a quoted string, or an alias.
- [[GhostYamlNumberDecoding]]: Scans and parses the numeric forms of YAML scalars: decimal integers and floats, hexadecimal, octal and binary integers, and `.inf` and `.nan`.
- [[GhostYamlPlainScalarFolding]]: The reader for plain (unquoted) scalars, including the ones that continue over several lines, and the check that tells a scalar from a mapping key.
- [[GhostYamlQuotedScalarDecoding]]: Reads double-quoted (`"..."`) and single-quoted (`'...'`) YAML scalars, with their escape rules and line folding.
- [[GhostYamlScalarDecoding]]: Decides which Kotlin type a plain YAML scalar becomes: null, boolean, integer, float or string.
- [[GhostYamlTags]]: Eight integer codes naming the core-schema types that a YAML tag can select.
- [[GhostYamlTagSubsystem]]: The parser for YAML tags such as `!!str`, `!<Circle>`, `!shape` and a bare `!`.
- [[GhostYamlValueReading]]: The central dispatcher of the YAML reader: `readValue` looks at the next byte and sends the parser to the right subsystem.
- [[GhostYamlWhitespace]]: The low-level scanning helpers of the YAML reader: whitespace, comments, indentation, directives and document markers.

- [[FlatByteArrayWriter]]: A growing byte array used as the in-memory output of `GhostJsonWriter`.

- [[GhostGenericByteSink]]: The basic byte-sink interface with no JSON-specific operations.
- [[GhostJsonWriter]]: The main low-allocation JSON writer: it turns Kotlin values into JSON bytes, either streaming to Okio or into an in-memory buffer.
- [[GhostJsonWriterBmpChar]]: An extension on Okio's `Buffer` that writes a quoted single character, UTF-8 encoded.
- [[GhostJsonWriterHelpers]]: Inline kernels shared by the JSON writers for structure, numbers and string handling.
- [[WriterSinkPair]]: A holder that pairs a `FlatByteArrayWriter` with the `GhostJsonWriter` that writes into it.

## writer/common

- [[GhostDoubleFormatter]]: A zero-allocation formatter that writes `Double` and `Float` values as ASCII bytes, with a safe fallback.
- [[GhostJsonEscapeHelpers]]: Shared inline helpers that decide which characters in a JSON string need escaping and write the escaped form.
- [[GhostWriterLongDigits]]: A helper object that writes the decimal digits of a `Long` backwards into a scratch buffer.

## writer/strings

- [[CharArrayCopy]]: The `expect` declaration of `copyRangeToCharArray`, plus the manual loop used on platforms without a native bulk copy.
- [[CharArrayCopy.jvmAndroid]]: The JVM and Android actual of `copyRangeToCharArray`, which copies part of a `String` into a `CharArray`.
- [[CharArrayCopy.nonJvm]]: The Native and Wasm actual of `copyRangeToCharArray`, which delegates to a shared loop.
- [[FlatCharArrayWriter]]: A growing `CharArray` used as the in-memory output of `GhostJsonStringWriter`.
- [[GhostJsonStringWriter]]: The char-channel JSON writer: it builds JSON text in a `CharArray` and is used by `Ghost.encodeToString`.

## writer/yaml

- [[GhostYamlWriter]]: The low-allocation writer that turns Ghost values into block-style YAML bytes.
- [[GhostYamlWriterHelpers]]: The stateless kernels behind [[GhostYamlWriter]]: layout, key quoting, string escaping and integer formatting.

## yaml

- [[GhostYamlErrorMessages]]: The central list of message texts (and message fragments) for YAML parse, write and lookup failures.
- [[GhostYamlPools]]: The common declaration of the two functions that lend a pooled YAML reader or writer to a block of code.
- [[GhostYamlPools.jvmAndroid]]: The JVM and Android implementation of the YAML reader/writer pool: one reusable reader and one reusable writer per thread.
- [[GhostYamlPools.nonJvm]]: The Kotlin/Native and wasm implementation of the YAML reader/writer pool, based on thread-local top-level variables.
- [[GhostYamlScanConstants]]: The numeric constants used by the YAML reader: digit bounds, limits, bit shifts, UTF-8 encoding and escape codes.
- [[GhostYamlTokens]]: The dictionary of fixed YAML syntax: the byte value of each structural character, the letters used in tags and scalars, and the literal words such as `true`, `null` and `---`.
- [[GhostYamlWriterConstants]]: A holder of the numeric and string constants that only the YAML writer needs.

## yaml/contract

- [[GhostYamlSerializer]]: The two-method interface that a type implements to be read from and written to YAML by Ghost.

## yaml/exception

- [[GhostYamlException]]: The exception thrown for invalid or unsupported YAML, with a path and an optional hint, plus the function that picks the hint.
- [[GhostYamlHintMessages]]: The texts of the fix suggestions that Ghost appends to YAML errors.

## yaml/serializer

- [[GhostYamlArraySerializerHelpers]]: Two inline loop helpers shared by all the primitive-array YAML serializers.
- [[GhostYamlBooleanArraySerializer]]: The YAML serializer for `BooleanArray`, a primitive array, written as a YAML sequence.
- [[GhostYamlCharArraySerializer]]: The YAML serializer for `CharArray`, a primitive array, written as a YAML sequence.
- [[GhostYamlDoubleArraySerializer]]: The YAML serializer for `DoubleArray`, a primitive array, written as a YAML sequence.
- [[GhostYamlFloatArraySerializer]]: The YAML serializer for `FloatArray`, a primitive array, written as a YAML sequence.
- [[GhostYamlIntArraySerializer]]: The YAML serializer for `IntArray`, a primitive array, written as a YAML sequence.
- [[GhostYamlListSerializer]]: A serializer for `List<T>` that works on the JSON channels and the YAML channel at once.
- [[GhostYamlLongArraySerializer]]: The YAML serializer for `LongArray`, a primitive array, written as a YAML sequence.
- [[GhostYamlMapSerializer]]: A serializer for `Map<String, V>` that supports JSON and YAML.
- [[GhostYamlSetSerializer]]: A serializer for `Set<T>` that supports the JSON channels and the YAML channel from one object.
- [[GhostYamlShortArraySerializer]]: The YAML serializer for `ShortArray`, a primitive array, written as a YAML sequence.
- [[NullableYamlSerializer]]: Adds YAML null handling to a serializer, so a `List<T?>` or similar keeps its YAML codec.
