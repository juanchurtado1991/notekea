# Checklist

## Opening
- [ ] Unlock, lights on, heater or aircon to 24°
- [ ] Check the sign-in tablet is charged
- [ ] Fill the water station
- [ ] Put out props for the first class

## Closing
- [ ] Wipe down mats
- [ ] Empty the bins
- [ ] Lock the back door and set the alarm
