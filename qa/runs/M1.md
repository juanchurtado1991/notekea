## Closed

Closed on 2026-11-01 with the macOS run of m1-rc1, as the developer decided: the Windows tester is not available
until M2, and Linux was not run. M2's QA run covers Windows and Linux again, with every General and M1 case.

- **macOS:** every automatic case passed. Of the manual cases, 5 failed (above) and 3 were not run; the report of
  m1-rc1 did not name them, so the manual rows marked ✅ assume the 3 were among the cases the manager lets testers
  skip (testable from later milestones). Since #104 the report names the cases not run.
- **Fixed in #104**, with no release candidate of their own (M2's run, from m2-rc1, checks them): 1.3-09, 1.4-13, 1.8-05, the case text of 1.4-08, the cut-off
  buttons of #101 and the noise in a report's last steps. **Deferred to M2:** 1.11-16 (#103).
